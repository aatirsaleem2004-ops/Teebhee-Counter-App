Tasbeeh Counter Engine
A simple command-line Tasbeeh (Zhikr) Counter built in Dart — track your daily zhikr with preset counters (SubhanAllah, Alhamdulillah, Allahu Akbar) or create your own custom zhikr with a target count.
✨ Features
🔢 Increment Counter — count up with each zhikr, auto-stops at target
🔄 Reset — reset any counter back to zero
📿 Preset Zhikr — quick-switch between SubhanAllah, Alhamdulillah, Allahu Akbar (via named constructors)
✍️ Custom Zhikr — create your own zhikr name + target count
📳 Completion Notification — vibration-style alert (via Mixin) when target is reached
✅ Status Display — shows current zhikr, count/target, and completion status
🖥️ Interactive CLI Menu — simple number-based menu system
